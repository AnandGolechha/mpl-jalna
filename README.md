# MPL Season 2 — Hindi + English website

This is a free static website for HKCC Cricket Club, Jalna. It uses the supplied MPL logo and the current registration form. CricHeroes is intentionally shown as "coming soon" because the tournament has not been created there yet.

## Before publishing
- Confirm with the organizers that registration is still open and the Google Form is correct.
- Replace the general rules in `index.html` and both language versions in `script.js` with the official tournament rules when provided. The current rules section is clearly marked as general information, not the official rulebook.
- Do not claim registration is limited or nearly full unless organizers confirm it.
- Do not publish private player information/photos without permission.

## Publish free on GitHub Pages
1. Download and extract this ZIP.
2. Create a public repository at https://github.com/new (e.g. `mpl-season-2-jalna`).
3. Upload the *contents* of this folder to the repository root. `index.html` must be at the root; include the `assets` folder.
4. In repository Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for deployment. The live URL will be shown in Settings → Pages, usually `https://YOUR-USERNAME.github.io/mpl-season-2-jalna/`.
6. Test the website on a phone, including Hindi/English toggle and registration form.
7. When the CricHeroes tournament is created, update the relevant text in `index.html` and `script.js`, or ask for a revision.

Official guide: https://docs.github.com/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Notes
- No backend, paid server, or domain is required.
- The website does not collect or store registration information; Google Forms handles the form.
- CricHeroes scoring is not duplicated.
- Hindi is the default language; visitors can switch to English with the top-right language buttons.
